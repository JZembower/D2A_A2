What to look for

γDrop it to 0.5. The values collapse, but the policy stays Right everywhere. Numbers on a dashboard can move a lot while behaviour does not move at all.
εRaise it. Q-learning's converged values do not budge. SARSA's get worse, because SARSA is honestly pricing in its own random steps.
Step 4The one step where nothing changes. The target already equals the estimate, so the temporal difference error is exactly zero.
Step 6The agent learns the sinkhole is bad by falling into it. There is no other way for it to find out.

What this bench actually demonstrates

The swapQ-learning reaches the same answer as backward induction without being told the rules. On tab 2 it lands on the exact optimum. It needs hundreds of thousands of episodes to do that on a five-cell problem. ``No model needed'' is not free. You stop paying for knowledge and start paying for experience.
CoverageOn tab 1, watch the third heatmap. Long queues almost never happen, so those cells are almost never visited, so their values are still whatever you initialised them to. The policy table still looks complete. It is not.
ExplorationTurn ε down to 0.02 on tab 1 and train. The learner stops finding out about actions it already believes are bad, and it locks in early. α will not save it. Exploration and learning rate are not substitutes.
Cost, not cellsCompare the realised cost of the two policies rather than the tables. A policy can be close to optimal in money while disagreeing about a great many states that hardly ever occur.

Questions worth asking about someone else's system

How many trials?If it learns from experience, how much experience, and who paid for it? A demo on a toy problem tells you nothing about the bill on a real one.
Show me coverageNot the output, the visit counts. A model that returns a confident answer for every input is not a model with evidence for every input.
Who is the sinkhole?If it learns online, somebody absorbs the exploration. In a consumer app that is an irritated user. In a benefits office it is a person whose claim went sideways.
Is it recoverable?Where a mistake is cheap and reversible, learning off-policy is fine and faster. Where it is not, a method that ignores its own randomness will overstate how well it does in production.
Did we need this?The most expensive mistake is not picking the wrong algorithm. It is spending data, months and goodwill to learn something you could have written down in an afternoon.

The update, in words

# This is the shape. Everything else is bookkeeping.

New Q value(s,a)  =  (1 - alpha) x Old Q value(s,a)  +  alpha x (new estimate of Q(s,a))

What is alpha?      How much we move towards the new information.
                    alpha = 0, learn nothing.  alpha = 1, throw away everything we knew.

What is the data?   The reward r, and the next state s'. That is ALL the
                    environment hands back. Not the model, not the probabilities.

What is the new
estimate?          The reward from now to the next step,           r
                    plus everything from s' onward.                gamma x (value of s')

And that last
term?              Either simulate forward and find out ... or just
                    read it off the table: max Q(s', a').
                    We can do that because of the very definition of Q:
                    cumulative future reward, reward to go, from (s,a).

Pseudocode  ·  reward convention (max)

Initialise Q(s,a) = 0 for every state-action pair
Choose alpha in [0,1], gamma in [0,1]

repeat for each episode:
    s <- starting state
    repeat until the episode ends:
        a  <- choose an action from s   (epsilon-greedy on Q)
        take a, observe reward r and next state s'

        target = r + gamma * max Q(s', a')     over all a'
        Q(s,a) = (1 - alpha) * Q(s,a) + alpha * target

        s <- s'

The two things you can change

COST instead of REWARD
    Everything flips sign, and:
        target = cost + gamma * min Q(s', a')
        act by argmin, not argmax
    Same algorithm. The hospital problem
    and Assignment 2 use this form.

SARSA instead of Q-LEARNING
    One term:
        Q-learning:  max Q(s', a')  over all a'
        SARSA:       Q(s', a') for the a' you
                     will ACTUALLY take next

    Q-learning assumes you behave greedily
    next period. With epsilon-greedy you will
    not. SARSA prices in its own randomness.
    That is off-policy versus on-policy, and
    it is the whole difference.

File 1  ·  the five-cell track, complete  ·  track.py

Runs in about a second. Prints the eight hand-worked steps, then trains to convergence and checks itself against the exact answer. If you change one thing in this file and rerun it, you will learn more than from any slide.

"""
The five-cell driving track from Lecture 5, start to finish.
Self-contained: no imports beyond numpy, runs in about a second.

Reward convention, so we use max.  Positions 0 and 4 end the episode.
"""
import numpy as np

L, R = 0, 1
ALPHA, GAMMA = 0.1, 0.9


def step(pos, action):
    """Return (next_pos, reward, done)."""
    nxt = pos - 1 if action == L else pos + 1
    if nxt == 0:
        return nxt, -10.0, True          # sinkhole
    if nxt == 4:
        return nxt, +10.0, True          # goal
    return nxt, -1.0, False              # ordinary move


def q_update(Q, s, a, r, s2, done, alpha=ALPHA, gamma=GAMMA):
    """One Q-learning update.  This is the whole algorithm."""
    target = r if done else r + gamma * np.max(Q[s2])
    Q[s, a] = (1 - alpha) * Q[s, a] + alpha * target
    return Q[s, a]


# ---------------------------------------------------------------- part 1
# The eight moves worked by hand in the lecture.
EIGHT_STEPS = [(2, R), (3, R), (1, R), (2, R), (3, R), (1, L), (2, L), (1, R)]

Q = np.zeros((5, 2))
print(f"{'step':>4} {'cell':>8} {'new value':>10}")
for i, (s, a) in enumerate(EIGHT_STEPS, 1):
    s2, r, done = step(s, a)
    v = q_update(Q, s, a, r, s2, done)
    print(f"{i:>4} {'Q(%d,%s)' % (s, 'LR'[a]):>8} {v:>10.4f}")

# ---------------------------------------------------------------- part 2
# Now let it run, and check it against the exact answer.
def run(n_episodes=200_000, algo="Q", eps=0.1, seed=1):
    rng = np.random.default_rng(seed)
    Q = np.zeros((5, 2))
    pick = lambda s: rng.integers(0, 2) if rng.random() < eps else int(np.argmax(Q[s]))
    for _ in range(n_episodes):
        s, a = 2, pick(2)
        while True:
            s2, r, done = step(s, a)
            if done:
                Q[s, a] += ALPHA * (r - Q[s, a])
                break
            a2 = pick(s2)
            boot = np.max(Q[s2]) if algo == "Q" else Q[s2, a2]   # <- the only difference
            Q[s, a] += ALPHA * (r + GAMMA * boot - Q[s, a])
            s, a = s2, a2
    return Q

# Exact optimal values, by working backwards from the goal.  This is
# backward induction, and Q-learning has to agree with it.
q3R = 10.0
q2R = -1 + GAMMA * q3R
q1R = -1 + GAMMA * q2R
print(f"\nexact:      Q(1,R)={q1R:.2f}  Q(2,R)={q2R:.2f}  Q(3,R)={q3R:.2f}")
Ql = run(algo="Q")
print(f"Q-learning: Q(1,R)={Ql[1,R]:.2f}  Q(2,R)={Ql[2,R]:.2f}  Q(3,R)={Ql[3,R]:.2f}")
Qs = run(algo="SARSA")
print(f"SARSA:      Q(1,R)={Qs[1,R]:.2f}  Q(2,R)={Qs[2,R]:.2f}  Q(3,R)={Qs[3,R]:.2f}")

File 2  ·  the agents  ·  agents.py

Cost convention. The method names match D2A_F26_HospitalStaffing.ipynb exactly, because Assignment 2 refers to them by name: choose_action, learn, greedy_policy. SARSA inherits from Q-learning so the only difference in the whole class is one line.

"""
Tabular Q-learning and SARSA, cost convention (we minimise).

The method names match D2A_F26_HospitalStaffing.ipynb exactly, because
Assignment 2 refers to them: choose_action, learn, greedy_policy.
Drop this next to any environment that exposes reset() and step(u).
"""
import numpy as np

rng = np.random.default_rng(42)


class QLearningAgent:
    def __init__(self, T, X_MAX, U_MAX, gamma=1.0,
                 epsilon=1.0, eps_min=0.02, eps_dec=2e-4,
                 lr=0.3, lr_min=0.05, lr_dec=5e-7):
        self.T, self.X_MAX, self.U_MAX = T, X_MAX, U_MAX
        self.gamma = gamma
        self.epsilon, self.eps_min, self.eps_dec = epsilon, eps_min, eps_dec
        self.lr, self.lr_min, self.lr_dec = lr, lr_min, lr_dec
        # hour, queue length, action.  Each +1 because 0 is a real value.
        self.Q = np.zeros((T + 2, X_MAX + 1, U_MAX + 1), dtype=float)

    def choose_action(self, t, x):
        """Epsilon-greedy.  argmin, not argmax: these are costs."""
        if t > self.T:
            return 0
        if rng.random() < self.epsilon:
            return int(rng.integers(0, self.U_MAX + 1))
        return int(np.argmin(self.Q[t, x, :]))

    def learn(self, t, x, u, cost, next_state, done):
        alpha = self.lr
        t_next, x_next = next_state
        q_old = self.Q[t, x, u]
        if done:
            target = cost
        else:
            target = cost + self.gamma * np.min(self.Q[t_next, x_next, :])
        self.Q[t, x, u] = (1 - alpha) * q_old + alpha * target
        self.epsilon = max(self.eps_min, self.epsilon - self.eps_dec)
        self.lr = max(self.lr_min, self.lr - self.lr_dec)   # decays alpha

    def greedy_policy(self):
        return np.argmin(self.Q[1:self.T + 1, :, :], axis=2).T

    def cost_to_go(self):
        return np.min(self.Q[1:self.T + 1, :, :], axis=2).T


class SARSAAgent(QLearningAgent):
    """Identical, except for one term.  learn() needs the NEXT action."""

    def learn(self, t, x, u, cost, next_state, u_next, done):
        alpha = self.lr
        t_next, x_next = next_state
        q_old = self.Q[t, x, u]
        if done:
            target = cost
        else:
            # Q-learning: cost + gamma * np.min(self.Q[t_next, x_next, :])
            target = cost + self.gamma * self.Q[t_next, x_next, u_next]
        self.Q[t, x, u] = (1 - alpha) * q_old + alpha * target
        self.epsilon = max(self.eps_min, self.epsilon - self.eps_dec)
        self.lr = max(self.lr_min, self.lr - self.lr_dec)


def train(agent, env, n_episodes=4000):
    scores = []
    for _ in range(n_episodes):
        state, done, total = env.reset(), False, 0.0
        while not done:
            t, x = state
            u = agent.choose_action(t, x)
            next_state, cost, done = env.step(u)
            agent.learn(t, x, u, cost, next_state, done)
            state, total = next_state, total + cost
        scores.append(total)
    return scores


def train_sarsa(agent, env, n_episodes=4000):
    """SARSA must choose the next action BEFORE it can learn."""
    scores = []
    for _ in range(n_episodes):
        t, x = env.reset()
        u = agent.choose_action(t, x)
        done, total = False, 0.0
        while not done:
            next_state, cost, done = env.step(u)
            t_next, x_next = next_state
            u_next = agent.choose_action(t_next, x_next) if not done else 0
            agent.learn(t, x, u, cost, next_state, u_next, done)
            total += cost
            t, x, u = t_next, x_next, u_next
        scores.append(total)
    return scores

File 3  ·  an environment  ·  env.py

The agents above will drive anything that exposes reset() and step(u). That is the whole interface. Swap this file for your own problem and nothing else changes.

"""Minimal environment. Anything with reset() and step(u) works with the agents."""
import numpy as np
rng = np.random.default_rng(42)


class HospitalEnvQL:
    def __init__(self, T=12, X_MAX=70, U_MAX=20, lam=17.0,
                 w=30.0, W=400.0, wage=500.0, base_docs=10, service_per_doc=2):
        self.T, self.X_MAX, self.U_MAX = T, X_MAX, U_MAX
        self.lam, self.w, self.W, self.wage = lam, w, W, wage
        self.base_docs, self.service_per_doc = base_docs, service_per_doc

    def reset(self, x0=None):
        self._t = 1
        self._x = int(rng.integers(0, self.X_MAX + 1)) if x0 is None else int(x0)
        return (self._t, self._x)

    def step(self, u):
        t, x = self._t, self._x
        u = int(np.clip(u, 0, self.U_MAX))
        cost = self.w * x + self.wage * u                 # immediate cost
        cap = self.service_per_doc * (self.base_docs + u)
        d = rng.poisson(self.lam)                          # the randomness
        x_next = int(np.clip(x + d - cap, 0, self.X_MAX))
        if t + 1 > self.T:
            cost += self.W * x_next                        # terminal penalty
            self._t, self._x = self.T + 1, x_next
            return (self.T + 1, x_next), cost, True
        self._t, self._x = t + 1, x_next
        return (t + 1, x_next), cost, False
